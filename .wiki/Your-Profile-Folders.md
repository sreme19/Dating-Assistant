# Your Profile Folders

Dating Assistant stores human-readable profile data inside the app directory and technical session data in your home directory.

## Female Profiles

Located at:

```text
Dating Assistant/female_profiles/
```

Each female profile folder can contain:

```text
female_profiles/
  jessica_Ambitious_Professional_e89f0f/
    profile.json
    preferences.md
    interviews/
      john_2026-05-19/
        conversation.md
    photos/
```

### `profile.json`

Structured identity and archetype metadata.

### `preferences.md`

The saved preference profile from AI Bestie preference gathering. Interview mode uses this file to tailor questions and compatibility reads.

### `interviews/`

Saved interview transcripts. These capture questions, pasted answers, and AI Bestie analysis.

### `photos/`

Optional profile visuals, usually downloaded or generated by `scripts/download-photos.mjs`.

## Male Profiles

Located at:

```text
Dating Assistant/male_profiles/
```

Each male profile folder can contain:

```text
male_profiles/
  kai_ENM_Polyamorous_w8m3ns/
    profile.json
    personality.md
    interviews/
      sarah_2026-05-19.md
    photos/
```

### `profile.json`

Structured identity and archetype metadata.

### `personality.md`

An AI-readable personality summary. AI Wingman uses this file when giving profile-specific advice.

### `interviews/`

Saved interview notes or transcripts connected to this male profile.

### `photos/`

Optional profile visuals.

## App Database

Technical app data lives here:

```text
~/.dating-assistant/
  config.json
  data.db
```

`config.json` stores local API config. `data.db` stores sessions, turns, knowledge bases, and related app state.

## Backup

To back up your data, copy:

- `Dating Assistant/female_profiles/`
- `Dating Assistant/male_profiles/`
- `~/.dating-assistant/`

## Photo Notes

Some profiles may have fewer than five photos. Empty `photos/` folders are not tracked by Git unless they contain a committed file.
