## How to Contribute

We welcome contributions from the community! See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.

### Ways to Contribute

1. **Code**: Submit pull requests for bug fixes or features
2. **Documentation**: Improve README, Wiki, or code comments
3. **Testing**: Add tests or report bugs
4. **Feedback**: Share ideas and suggestions
5. **Translations**: Help translate documentation
